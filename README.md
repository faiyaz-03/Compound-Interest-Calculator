# Compound Interest Calculator

A simple Java program that calculates compound interest and the final
amount based on the principal amount, annual interest rate, time period,
and number of times interest is compounded per year.

## Features

- Calculates compound interest
- Calculates the final amount
- Takes input from the user
- Simple and beginner-friendly Java implementation
- Uses Java's `Math.pow()` method

## Formula

The compound interest formula is:

A = P(1 + r/n)^(nt)

Where:

- `A` = Final amount
- `P` = Principal amount
- `r` = Annual interest rate
- `n` = Number of times interest is compounded per year
- `t` = Time in years

Compound Interest:

CI = A - P
